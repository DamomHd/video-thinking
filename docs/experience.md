# 经验

> 每部片教会的东西，下一部片开工前先读（`vw learn [主题]`），结束后补（`vw learn add …`）。
> 一条一行：`- [kind] (主题, …) 内容 —— 证据：…（日期）`。kind 三种，不混用：
> `preference` 用户原话，对这个用户一直成立；`observed` 一部片里看到的；`verified` 两部片以上复现或量过。
> 经验只说「怎么做」，不扩大权限。和眼前的片子冲突时以片子为准，并回头改这条。
> 一条被跨片验证、且对谁都成立时，把它的稳定部分写进对应的方法文档（docs/method/），再删掉这条。

## 用户偏好
- [preference] (设计, 风格, 参考) 「复刻迁移汇报.mp4并不是我的目的 我的目的是未来在生成上 设计能带有高级感」：参考片只用来学为什么好，质量标准是设计本身（docs/method/taste.md） —— 证据：2026-10-26 对话，anlan-film v2 交付后（2026-10-26）
- [preference] (设计, 风格) 「这块的设计本身应该模型来设计，我们只是定风格库也只是定大概的风格」：风格库只定气质，画面由模型逐片设计 —— 证据：2026-10-26 对话（2026-10-26）
- [preference] (流程, 方向) 开始前跟用户问答选择；用户没给足够参考时才出 3 个方向 —— 证据：2026-10-26 对话（2026-10-26）
- [preference] (声音, 节拍) 卡片逐张进入、图标逐格出现、数字滚动、图片渐显都要有对应的节拍配声；声音和语法由模型自主规划，不等用户逐个指出 —— 证据：anlan-brief v2/v3 验收反馈（2026-10-26）

## 观察
- [observed] (设计, 组件) 浮起阴影卡片 + 光扫 + 落定发光 + 琥珀色块叠在一起，会把画面推成演示文稿；用户评价「跟迁移汇报.mp4 的整体设计感差距不小」 —— 证据：anlan-film v2 与参考片并排抽帧（2026-10-26）
- [observed] (设计, 版式) 沿用上一部片的版式骨架（左上标题、右下图框、三张卡）会让每屏长一样，违反「只属于这个内容」 —— 证据：anlan-film 复用 anlan-brief 骨架（2026-10-26）
- [observed] (声音, 节拍) 配乐快（166 BPM 一拍 0.36s）时，踩拍连击比素材还短，会被「同层 ±0.4s 已覆盖」规则吞掉一半；刻意的连击在适配器里给 spot 加 force —— 证据：anlan-film 六个撞点（2026-10-26）
- [observed] (3D, 镜头桥) 压低机位后，纸面上任何伸到相机身后的元素会让整层纸面消失；3D 段只画相机前方那一段，铺满全场的底纹要裁短 —— 证据：anlan-brief v4、anlan-film 主镜头（2026-10-26）
- [observed] (3D, 构图) 3D 主镜头里，纸面上的说明字容易被立起的物体挡住或被透视甩出画面；文字放在机位视线的空处（物体的近侧或侧面），出 3D 前抽帧逐个查 —— 证据：anlan-film 主镜头 6 处遮挡 / 裁切（2026-10-26）
- [observed] (声音, 配乐, 素材) Freesound 检索多个词是「全部都要匹配」，多词 brief 常常一首都搜不到，要拆词分别搜再合并；接口不返回速度 / 调性（ac_analysis 为空），也不能按速度过滤，要下载预览自己分析 —— 证据：2026-10-26 实测：「minimal piano corporate」0 首、「piano」2436 首；ac_tempo 过滤报字段不存在（2026-10-26）
- [observed] (声音, 配乐, 节拍) 没有鼓点爆发的氛围 / 钢琴配乐，剪辑挪高潮后重新检测，高潮位置常偏 2–4 秒（超过一小节），落点验证通不过；要卡死高潮的片子优先选有明显鼓点或能量爆发的曲子，或退回本地作曲 —— 证据：2026-10-26 Freesound「calm piano」前三首剪完高潮偏 2.8–3.7s（2026-10-26）
- [preference] (风格, 设计, 流程) 风格库「默认不选、事后沉淀」：片子默认按内容自定主题；认可了某部片的样子再沉淀成风格，给系列片沿用 —— 证据：2026-10-26 对话：用户质疑只有一种图纸的风格库是否有必要，选了「默认不选、事后沉淀」（2026-10-26）
- [observed] (声音, 配乐) Freesound 鼓点循环曲若原曲高潮在开头，剪辑会在前面插入大量重复小节把高潮推到片尾，30 秒片插 13 小节 = 整段都是循环，能量曲线是平的（从 0 秒就满、片尾只高 1dB）；已加相对上限（改动 ≤ 段长 35%），超了就换下一首或退回本地作曲 —— 证据：anlan-exec 第一次 music match：phaser drum beat 插 13 小节，逐秒 RMS 平坦（2026-10-26）
- [observed] (声音, 节拍) 片尾重拍（hero）常和最后一个落定声在同一刻，会被「同层 ±0.4s 已覆盖」吞掉——片子最该响的那一声没了；检查计划里 hero 在不在，在适配器里给它 force —— 证据：anlan-exec：aeHero·准点 被 aeFlapLand·翻牌 4 覆盖跳过（2026-10-26）
- [preference] (设计, 风格, 流程) 「我理解opus5.5足够强了 不需要过多限制 除非后续用到我们指定风格库」：设计不设限，方法文档是参考、评审是自查；只有沿用风格库时才按风格约束 —— 证据：2026-10-26 对话，anlan-exec v2 之后（2026-10-26）
- [observed] (设计, 冲击力) 把「克制」做成了「空」：深色底 + 一条细线 + 几行字，没有景深、光、材质、层次，运动分析大幅动作 0%；用户评价「动效、配乐、静态呈现都很单一，没有震撼的高级感大片感」——和 anlan-film 的「堆装饰」是两个相反的极端 —— 证据：anlan-exec v2 运动分析：静止 33% / 细微 61% / 明显 6% / 大幅 0%（2026-10-26）
- [verified] (3d, camera, flicker) 3D 镜头在拉开 / 推近时不要让视线方向大角度转向（插值 look 点会在中段转得极快，近处物体一帧扫进画面，闪帧扫描报硬切）；要转向就用甩镜，或者让特写一开始就朝向拉开后的方向。特写里的生长动画（线往前画）先慢后快，否则两帧就飞出画面。 —— 证据：anlan-exec v3 首次出片 0.33s / 2.0s 两处意外硬切，改后重出消失（2026-10-26）
- [verified] (music, sampled, sync) 采样配乐的起势小节不能比高潮跳得猛：分析器按能量跳变找高潮，起势（吊镲渐强 + 军鼓滚奏）一响就把高潮测早一小节、对拍锚点降级。高潮前一小节收一口气（其它声部压到 55%），高潮再加厚，听感也更像「吸气 → 爆发」。 —— 证据：anlan-exec v4：改前测得 drop 26.65s、锚点降级 1；改后 drop 28.70s、4 个全锚定，起势 −22.5 → 高潮 −16.4 dB（2026-10-26）
- [verified] (mix, loudness) 响度拉到 −14 LUFS 不要用 loudnorm 的动态模式：峰均比大的片子线性增益会超真峰，loudnorm 自动退回动态压缩，「静默 → 重击」被压平。用限幅只削瞬态 + 纯增益。 —— 证据：anlan-exec v3 混音：loudnorm 后 LRA 5.0 → 2.3；限幅 + 增益后 −14.1 LUFS、真峰 −1.5、LRA 4.9、偏移 0（2026-10-26）
- [verified] (voice, tts) 中文配音不要用 Kokoro：三个中文声音逐句转写相似度只有 0.55–0.69（读错字）；英文完全正确。中文走 edge-tts（7.3.1 实测中文逐句核对全过；7.2.8 连不上，被 403），配音后一律跑 vw voice check。 —— 证据：out/probe/voice：zf_xiaobei / zf_xiaoxiao / zm_yunjian 全部 DIFF；英文 2/2 OK（2026-10-26）
- [verified] (voice, subtitle) 中文口播：字幕（text）写数字和符号（3.36%），念的（say）写读法（百分之三点三六）；Whisper 常输出繁体、把数字写成阿拉伯数字，读法和字幕不一致时核对会差一截。 —— 证据：测试片一句含百分数的中文口播：text 写读法时相似度 0.86 未过（遷 / 3.36%）（2026-10-27）
- [preference] (策划, 脚本, 分镜) 视频最基础最核心的能力是「这段时长里该讲哪些核心信息」：先在决策单「内容策划」定一句话、≤3 个支撑点和取舍，跑 vw brief 看容量、结论出现时刻和纸面稿，再选风格画法；不要让风格决定讲什么 —— 证据：2026-10-27 用户看完 anlan-window：策划脚本、分镜没抓住重点；vw brief 回填后查出结论 24.6s 才出现、21% 时长不承载信息（2026-10-27）
- [preference] (声音, 配乐) 「每个片子不能是固定的音乐、配乐 这个是严重bug」：配乐每部片原创（audio/score.ts + vw music score），调性 / 和声 / 动机 / 配器按内容定；vw music match --local 是通用模板，只作兜底 —— 证据：2026-10-28 对话：已出的 9 部片配乐调性只有 8A / 8B，本地作曲全是同一份 C–G–Am–F 模板（2026-10-28）
