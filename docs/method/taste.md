# 高级感从哪来

> **这是参考，不是规则。** 没有指定风格库时，画面怎么设计完全由模型自由发挥；下面的原则、常见的坑、评审表都是帮助思考和自查的工具，不是禁区。只有片子沿用了风格库里的某个风格时，才按那个风格的 README 约束。
>
> 本工程的设计标准。不是「像不像某部参考片」，而是设计本身好不好。
> 整理自：huashu-motion（`director.md` 片级规则、`visual-direction.md`、`colour.md`、`craft.md`）、huashu-design（反 AI 套路清单、设计评审五维）、emil-design-eng（细节复利），按本工程的视频场景改写。2026-10-26。

## 一句话

**高级感 = 精确 + 每一层都有目的；大片感 = 在这个基础上有尺度、光、深度和冲击。** 两样都要。
「廉价感」来自**无目的的默认值和装饰**（没想过为什么就用上的阴影、发光、渐变、图标、色块）——问题是「无目的」，不是光、深度、材质本身。
「单一感」来自另一个极端：把克制做成了空——一层底、一条线、几行字，没有景深、没有光、没有层次、没有一个让人记住的瞬间（anlan-exec v2 的教训）。

## 七条原则

1. **有目的（不是「少」）**
   - 强调色给真正要强调的东西；多处都强调 = 没有强调。
   - 每屏一个视觉主体；其余是它的注释或它所在的空间（前景、中景、背景都可以有东西，但要分得出主次）。
   - 留白是设计的一部分，但「空」不是：一块画面空着，要么是在为下一刻蓄力，要么就该有空间、光或材质在里面。
2. **层级**
   - 字号对比要拉得开：大标题和注释差三到四档，不是差两号。
   - 一眼看得出先读什么、再读什么。标题是一句结论（「范围收到最小。」），不是一个话题（「本次迁移范围」）。
   - 大字只给一个数字或一个词。
3. **工艺（近看经得起）**
   - 对齐到网格；间距成体系（同类元素间距一致）；线宽有层级（1px 结构线 / 1.5px 主体 / 更粗只给强调）。
   - 字体真用字重对比；数字用等宽；中英文混排看基线。
   - 曲线连接处、箭头、端点、接触阴影都要经得起放大到 200% 看。
   - 先按最终分辨率渲出来看，不在缩略图上判断。
4. **运动在解释**
   - 每个动作都有一个动词：汇聚、拆分、对齐、连接、筛选、揭示、替换。说不出动词的动作就是装饰。
   - 变化本身就是解释（21 个接口变成 6 个，比一页写着「6 个」更有说服力）。
   - 停住也要有值得看的东西：每一次停留都应该是一张能当海报的画面。
5. **节奏是对比**
   - 快与慢、远与近、动与静、密与疏。全程一个速度、一种缓动，再精致也会无聊。
   - 有钩子（前 3 秒）、有蓄力、有释放（最大的揭示放在音乐最强的点）。
6. **冲击力（大片感）**——每部片至少要有一个让人记住的瞬间，平常也要有空间感：
   - **尺度反差**：极近特写 ↔ 全景；一个小东西和它所在的巨大系统放在同一个镜头里。
   - **速度反差**：慢推 / 慢漂之后来一次甩镜、穿越式推进、速度曲线骤变；一段 3–5 秒的短促快切爆发。
   - **深度与层次**：前景虚化掠过、中景主体、背景有远处的结构；视差；3D 空间（镜头桥、实时 3D、Blender）。
   - **光**：主光与环境、体积光、辉光、反射——光要像在照亮一个真实的空间，而不是贴一层特效。
   - **材质**：实体的东西要有质地（金属、玻璃、纸、陶瓷），哪怕只是在主镜头里。
   - **静默与重击**：最大的那一下之前，画面和声音一起抽空半拍；之后低频重击、光炸开、镜头急推。
   - **声音是一半**：冲击感一大半来自声音的低频、上升音和停顿，画面再好配上单薄的声音也起不来。
7. **只属于这个内容**
   - 换一个题目、换一个产品名还长一样，就不合格。
   - 画面的形状和词汇从内容里长出来（迁移 → 轨道与道岔；锁窗口 → 一面墙），而不是从上一部片的模板里来。

## 常见的坑（参考）

这些东西本身不一定丑，问题是它们是「没想过就用上」的默认值，不携带任何关于内容的信息：

| 套路 | 为什么廉价 | 什么时候可以用 |
|---|---|---|
| 圆角卡片 + 阴影 + 浮起 | 网页 / 演示文稿的默认语言，所有东西都长成一张卡 | 内容本身就是卡片（UI 截图、票据） |
| 落定时的光扫、发光 | 「高级感特效」的万能公式，用多了等于没用 | 全片只有一两处、而且那一刻确实是高潮 |
| 大面积色块填充 | 稀释强调色；看起来像幻灯片配色 | 风格本身就是色块（扁平插画） |
| 渐变背景 | AI 科技感的最大公约数 | 品牌本身就用 |
| 每个标题配一个图标 | 图标在凑数，不在解释 | 图标本身是被讲的对象 |
| 无意义的粒子、光点、数字装饰 | 装饰大于内容 | 光点代表真实流动的东西（交易、数据包） |
| 每屏同一套版式（左上标题、右下图框、三张卡） | 观众第二屏就知道第三屏长什么样 | 片子刻意做成「章节体」时，版式统一但内容形态要变 |
| 暖白底 + 一个橙 / 青柠强调色 + 巨大的无衬线字 + 等宽小字 | 2026 年 AI 做的片子的「房子风格」（huashu-motion 实测） | 确实是这个品牌 / 风格时，说清楚为什么 |

本工程两次跑偏的教训，方向相反，都要避开：
- anlan-film v2：浮起 + 光扫 + 发光 + 琥珀色块**无目的地叠在每一张卡上** → 演示文稿感。问题是无目的、到处都用，不是这几样手法本身。
- anlan-exec v2：为了避开上一条，把光、深度、材质全拿掉 → 单一、空、没有大片感（运动分析：大幅动作 0%）。

光、深度、材质、发光都是正当的手法；判断标准只有一个：这一层在为画面的主体做什么。

## 三种不好，三种修法

先判断是哪一种，别用错补丁（huashu-motion `visual-direction.md`）：

| 症状 | 先查 | 不要先做 |
|---|---|---|
| **看着廉价** | 构造、字形、线宽、对齐、颜色数量、装饰 | 加运镜、加特效 |
| **看着无聊** | 每段有没有新信息、景别和速度有没有对比、落点踩没踩拍 | 加粒子、加装饰 |
| **看不明白** | 焦点是否唯一、对象身份是否清楚、读字时间够不够 | 堆字幕、堆说明 |

## 设计评审（关卡）

两处必须过：**四张海报帧**（开场、主镜头、最密的一屏、结尾）定稿时，和**交付前**（成片缩略图 + 关键帧）。由模型按下表自评，写进决策单「设计评审」一节。（独立审片者冷看是 TODO。）

| 维度 | 看什么 | 7 分的样子 |
|---|---|---|
| 风格一致性 | 每一帧都在同一个气质里；强调色、线宽、字的用法前后一致 | 没有哪一屏「换了一套设计」 |
| 视觉层级 | 每屏一个焦点；字号对比；先读什么一目了然 | 截任意一帧，三秒内说得出它在讲什么 |
| 细节工艺 | 对齐、间距、线宽、字形、端点、遮挡、裁切 | 放大到 200% 没有明显瑕疵 |
| 信息清晰度 | 数据准确、读字时间够、变化在解释 | 关掉声音也看得懂主线 |
| 原创性 | 只属于这个内容；没有套路清单里的东西 | 换个题目放不进去 |
| 冲击力 | 有没有一个让人记住的瞬间；尺度、速度、深度、光、声音有没有反差；画面有没有空间感 | 看完能说出「那一下」是哪一下；运动分析里有明显 / 大幅动作，不是全程细微 |

规则：
- 每项 1–10 分；低于 7 的项建议先改再往下走（自查，不是关卡）。
- 分数必须配**具体缺陷**（哪一帧 / 哪个时间点 / 哪个元素 / 怎么改），没有缺陷描述的高分无效。
- 不能自封高分：用户否定过的画面，不能再拿来当好例子。
- **校准**：自评容易手软（anlan-exec v2 自评 7–8，用户的感受是「单一、没有大片感」）。打分前先问：这一帧放在一部真正的大片旁边，会不会显得空？会，就不到 7。

## 海报测试

> 「如果一张静帧当不了海报，成片也不会好。」（huashu-motion）

四张海报帧按最终分辨率渲出来（`vw still`），一张一张看：拿掉动画，它本身是不是一张好的图？这是最便宜、最早能发现问题的一关。
