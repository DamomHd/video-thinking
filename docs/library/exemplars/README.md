# 好例子

每个样本一份笔记：**它为什么好、用了 `docs/method/taste.md` 的哪几条原则、能迁移到别的题材的是什么、不该照搬的是什么**。学原则，不复刻画面。

写法：
- 观察和推测分开写（看得见的 vs 我认为的）。
- 每条原则配一个具体的时间点或画面。
- 写清「换个题材还能用的部分」——这才是收这个样本的意义。

新样本：`vw ref <视频> --out=docs/library/exemplars/<id>`，抽帧、拼缩略图，生成 `<id>/notes.md` 模板，按模板写。

| id | 样本 | 一句话 |
|---|---|---|
