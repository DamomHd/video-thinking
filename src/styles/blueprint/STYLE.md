# 图纸 · Engineering Blueprint

自有风格：沉淀自一部工程制图画法的项目汇报参考片（3 分 05 秒，原片和参考帧是业务资料，只在作者本机，不进仓库）和本工程照它做的汇报片。
基准作品就是样片：`refs/demo.mp4`（软链到仓库根目录的原片），量出来的数据见 README；为什么它显得高级，见 `docs/library/exemplars/migration-report/notes.md`。

> 一部把要讲的东西当成**一张真的工程图**来讲的片：暖白纸、点阵网格、图框和标题栏，墨线是主角；每一段用一种从内容里长出来的工程画法（等轴测分层、逐行对照表、铁轨与道岔、时间轴），旁边是编号、引线和等宽小字；颜色几乎只有黑灰白，唯一的强调色只给「正在流动的那件东西」。
> 用途：项目汇报、技术方案、架构 / 链路 / 迁移讲解——关系复杂、数据不多、要让人相信「这件事被想清楚了」的内容。

## 1. 本质，以及它不是什么

- **一张图纸贯穿全片**：每一帧都在同一张纸上、同一个图框里（四边分区刻度、四角对位十字、右下角标题栏），标题栏里的图号随段落变（AL-04、AL-07……）。观众感觉是在翻一套图，而不是看一组幻灯片。
- **标题是结论，不是话题**：每段左上一行小号编号，下面一句粗黑短句，带句号（「范围收到最小。」「七个下游接口，收成两个。」），后面的图都在证明这一句。
- **每段的画法从内容里长出来**：迁移 = 换轨，所以切流画成铁轨和道岔；架构 = 分层，所以画成等轴测分层板；对照 = 一张逐行比对的表。同一部片里不重复同一种版式，统一的是气质，不是版式。
- **一根脊梁**：一条线（轨道、光、时间轴）把各段串成一部片。
- **克制**：强调色只给一件事；没有口播；镜头几乎不动。

不是 product-story（暖纸产品叙事）：那是圆角卡片、真实感界面和单据、暗场金光；这里没有卡片、没有阴影，只有线和字。不是 PPT（没有项目符号堆砌、没有每页相同的标题条）；不是科技发布（不靠黑底和发光）；不是信息图海报（每一屏只有一个主体）。

## 2. 材质与渲染

- **纸**：暖白 `paper`（#F8F6F2），深一级 `paperDeep` 做分区底；细点阵网格 `gridDot`，极淡的网格线 `grid`。
- **图框**：离边 42px，四边分区刻度 1–6 / A–D（`frame` 段），四角对位十字，右下角两行标题栏（片名 · 段名 · 图号）。每一帧都有、位置不变（暗场时反相）。
- **线是主角**：1–1.5px 细线为主；墨线阶梯 `line` / `lineMid` / `lineThin` 是语义——粗细、实线 / 虚线 / 点线、双轨加枕木，各有含义，一部片里含义固定。
- **画法**：等轴测分层板（架构）、逐行比对表 + 大计数（双跑 / 对账）、铁轨与编号道岔（切流 / 路由）、时间轴与里程碑（计划）、编号圈 + 引线 + 等宽注释（标注）。
- **不要**：圆角阴影卡片、实心色块、渐变、处处发光、照片和实拍。需要「框」时用细线矩形，不用卡片。
- **暗场**（可选，少用）：整张图反相成墨底（`ink`），线和字用 `onInk` 一族；适合「只看这一段时间 / 这一个窗口」的数据段。

## 3. 配色逻辑

- **黑灰纸白占绝大多数**：`ink` / `text` 黑，`textMid` / `textFaint` 两级灰，纸白。九成以上的像素只有这些。
- **一个强调色，只给一件事**：`accent`（默认暖黄 #C98A1E，浅底 `accentSoft`、亮 `accentDeep`）只给「正在流动 / 正在变化的东西」——铁轨上的光、发光的那一段轨、当前这一步。片子派生时通常只换这一组。
- **状态色极少量**：`ok` 绿只出现在一个对勾上；`bad` 红 / `warn` 橙只在真正的风险上，出现即被解决。
- 多处都强调 = 没有强调：一屏里强调色只能落在一个主体上。

## 4. 字体与字幕

- **编号行**：左上，等宽小号灰字，`— 06 · 灰度切流 · 逐笔判断`。
- **标题**：中文粗黑（PingFang SC / 思源黑体），一句结论、带句号，左上对齐。
- **注释**：大量等宽小字（`mono`），贴着引线和编号圈；表格数字等宽对齐。
- **大字**：只给一个数字或一个词（`1/17`、`7 → 2`、`换轨`），细或常规字重。
- **字幕**：没有口播就没有字幕；要说的话写成标题和注释。有口播时用 Subtitles，小号、浅底深字、底部居中，不压图框标题栏。
- 屏幕上的字都要停够读完（`vw readcheck`）。

## 5. 动效手感

- **画出来，而不是飞进来**：线从一端描到另一端（stroke），注释沿引线出现，编号圈先落点再展开；不做弹跳、缩放入场。
- **镜头几乎不动**：基准作品 82% 的时间是静止的，动作段中位 0.3 秒；段内最多极缓的推近，段间平移到图纸的下一块区域（同一张纸）。
- **流动只给强调物**：光点沿轨道走、发光那段轨推进；其余元素落定后不再动。
- **形变挪位**：数量收缩（21 → 6、7 → 2）用元素真的挪位、合并来表达（MorphLayer），不是换一页。

## 6. 镜头语法

| 镜头 | 表达 | 适合 |
|---|---|---|
| 正俯视整张图，主体占 60–70% | 一张被想清楚的图 | 每段的主镜头 |
| 沿脊梁平移到图纸的下一块 | 同一件事的下一步 | 段与段之间 |
| 极缓推近一个编号圈 / 一个道岔 | 关键细节经得起看 | 段内的读点 |
| 等轴测分层板 | 架构、层次、新旧对照 | 系统架构、迁移映射 |
| 逐行比对表 + 大计数 | 核对、一致性 | 双跑、对账、验收 |
| 铁轨与编号道岔 | 路由、切流、分支 | 灰度、分流、规则判断 |
| 时间轴 + 里程碑 | 计划与当前位置 | 排期、上线 |
| 反相暗场 | 只看这一段 | 时间窗口、单一数据 |
| 道岔特写 + 大字 + 一排数字格 | 收束 | 落版 |

## 7. 声音调色板

- **没有口播**；配乐安静、低速（anlan-report：本地合成，约 86 BPM），动态大（基准作品 LRA 14.8 LU），不抢图。
- **拟音是纸面上的声音**：房间底噪、笔划 / 描线、盖章 / 机械咔嗒、翻页、木质闷响。都很轻、很干。
- **重拍极少**：一部片一两次（换轨那一下、落版），其余靠留白。
- **混音**：−14 LUFS 母带；基准作品整体 −16.8 LUFS、真峰 −2.1。

## 8. 原生手法（标志性的那一下）

按内容挑，用一两个就够。

- **换轨**：一条轨道上的光走到道岔，道岔扳过去，光走上新轨。*适合*：迁移、切流、路由切换。
- **收成几个**：一排元素（接口、模块）熄灭大半，剩下的挪位合并，大字 `21 → 6`。*适合*：范围收敛、合并、精简。
- **分层板对位**：两组等轴测分层板，一条虚线从旧的一层连到新的一层。*适合*：架构映射、新旧系统对照。
- **逐行对上**：一张表逐行打勾，大计数从 `0/17` 走到 `17/17`。*适合*：核对、验收、双跑。
- **图号翻页**：标题栏里的图号随段落翻动（AL-04 → AL-05），像在翻一套图纸。*适合*：任何多段汇报。

## 9. 媒介的坑

- 一加阴影卡片、实心色块、光扫和落定发光，图纸就塌成演示文稿（经验：anlan-film v2，用户评价「跟迁移汇报.mp4 的整体设计感差距不小」）。
- 强调色撒在多处：每屏数一下，强调色只能在一个主体上。
- 细线在缩略图里会消失：关键线用 `line`（深）而不是 `lineThin`；成片抽帧检查。
- 等宽小字太多太小：注释是给愿意细看的人的，标题和大字必须独立成立。
- 铁轨、道岔、等轴测板本身不是风格：换个题材要找那个题材自己的工程画法，不要照搬。
- 世界层里的文字绝对定位要给宽度，否则会一个字一行（AGENTS §9）。

## 10. 引擎（本工程怎么做）

- 纸与图框：`style.ts` 的色板与 `frame` 段；`shot/Light` 的 `PaperLight`（放在 Stage 外面作为同级）。
- 线与描画：`shared/motion` 的 `stroke` / `draw`；`shot/PathPulses`（沿路径的光点）；`shot/MorphLayer`（挪位、合并）；`geo/` 几何板书。
- 字：`shot/FocusText`（逐字聚焦）；编号、标题栏按片子在 `scenes/` 里画。
- 镜头：`shared/grammar.ts` 镜头清单（still / push / drift + glide / arc / cut）；需要立体时 2D↔3D 镜头桥（`shared/bridge.ts`）。
- 样张：`vw style sheet blueprint`。
- 在真片里用过：anlan-report（主题照它写）、anlan-brief / anlan-film（`extendStyle(BLUEPRINT, …)`）。

## 11. 变化空间（每部片可以自由变的）

强调色（只换 `accent` 一组）、每段的工程画法（按内容找）、脊梁是什么（轨道、光、时间轴、管线）、段数和长度、是否用暗场、是否用 3D（镜头桥）、图框的分区数和标题栏文字、配乐的乐器（安静、低速的范围里）。
