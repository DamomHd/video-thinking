# 改了什么

图纸不是从库里的风格改出来的：它是**沉淀**的（用户认可参考片 `迁移汇报.mp4` 和照它做的 anlan-report 后收进库）。这张表记的是沉淀时相对基准作品做的取舍，以及 2026-10-27 按风格库规范补全时的决定。

| 节 | 基准作品 | 现在 | 为什么 | 分组 |
|---|---|---|---|---|
| 本质 | 一部片（迁移汇报） | 一套可复用的气质：一张图纸贯穿、标题写结论、画法从内容里长出来 | 风格要能用在别的题材上；铁轨和道岔只属于「换轨」这个题材 | 一改就变味 |
| 材质 | 图框、点阵、细线，没有卡片 | 照收；`frame` 段把图框参数化（边距、刻度、分区） | 片子可以调图框尺寸，但不能去掉图框 | 一改就变味 |
| 配色 | 暖黄只给流动的交易，绿只给一个对勾 | 照收；强调色做成可替换的一组（`accent` / `accentSoft` / `accentDeep`） | 系列片换强调色就能区分，规则不变 | 放心改 |
| 字体 | 编号 + 粗黑结论句 + 等宽注释 | 照收 | 这是它显得「想清楚了」的主要原因 | 一改就变味 |
| 动效 | 画出来；82% 时间静止 | 照收；加「形变挪位」表达数量收缩 | anlan-report 里用过，比换页更像图纸 | 放心改 |
| 镜头 | 正俯视 + 平移 | 照收；允许暗场反相、2D↔3D 镜头桥 | anlan-report / anlan-film 的扩展，按内容可选 | 放心改 |
| 声音 | 无口播、安静、动态大 | 照收；拟音限定为纸面上的声音（笔、章、页、木） | anlan-report 的配声方案 | 放心改 |
| 规范 | 只有 README 气质描述 + 4 张参考帧 + notes.md | 补全 STYLE.md（十一节）、CHANGES.md、poster.jpg、styleframe.png（anlan-report 33s）、demo.mp4（软链原片）；notes.md 并入 STYLE.md | 2026-10-27 用户定：风格库规范统一，方便维护迭代 | — |
