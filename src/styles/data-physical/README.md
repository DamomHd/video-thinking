# 数据实物化 · Data Physicalization

> 收录自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（LemoLab，commit `413a6bd`）· 分类：实证影像（Evidence Films）

**一句话**：十二年风电和太阳能装机叠成实物，绕表盘升成两条螺旋，2021 年太阳能反超。（Twelve years of wind and solar stacked as real plates, spiralling round a walnut dial until solar overtakes.）

**适合**：Annual reports · Investor decks · Energy data

## 文件
- [`STYLE.md`](STYLE.md)：风格提示词原文——**选了这个风格就按它做**（本质与边界、材质、配色逻辑、字体与字幕、动效、镜头语法、声音、原生手法、媒介的坑、变化空间）。
- [`DEMO.md`](DEMO.md)：上游样片《Two Spirals》（39.4 s）的说明，只是一个例子，不要照搬它的故事、镜头和时间。
- `style.ts`：参考色板与字体（风格库现有字段）。**色板只是参考**：片子用这个风格时，配色由模型按片子的需要、照 STYLE.md 的配色逻辑自己定。
- `refs/poster.jpg`、`refs/frame.jpg`：样片海报帧和画廊关键帧。
- 样片源码（Canvas / WebGL 页面 + 配乐混音脚本 + 字体）：`vw style demo data-physical` 取到 `out/styles/data-physical/demo/`，读来学手法，不在本工程里渲。
