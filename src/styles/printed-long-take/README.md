# 印刷长镜头 · Printed Long Take

> 收录自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（LemoLab，commit `f171360`）· 分类：印刷与版画（Print & Printmaking）

**一句话**：刮版画的北海道河谷一镜到底，丹顶鹤从 33 只数回到 1,927 只。（Red-crowned cranes in a Hokkaido valley, one scratchboard take, counted back from 33 to 1,927.）

**适合**：Journeys · Wildlife · Landscapes

## 文件
- [`STYLE.md`](STYLE.md)：风格提示词原文——**选了这个风格就按它做**（本质与边界、材质、配色逻辑、字体与字幕、动效、镜头语法、声音、原生手法、媒介的坑、变化空间）。
- [`DEMO.md`](DEMO.md)：上游样片《Thirty-Three Cranes》（60 s）的说明，只是一个例子，不要照搬它的故事、镜头和时间。
- `style.ts`：参考色板与字体（风格库现有字段）。**色板只是参考**：片子用这个风格时，配色由模型按片子的需要、照 STYLE.md 的配色逻辑自己定。
- `refs/poster.jpg`、`refs/frame.jpg`：样片海报帧和画廊关键帧。
- 样片源码（Canvas / WebGL 页面 + 配乐混音脚本 + 字体）：`vw style demo printed-long-take` 取到 `out/styles/printed-long-take/demo/`，读来学手法，不在本工程里渲。
