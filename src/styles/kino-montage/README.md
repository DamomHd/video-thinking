# 构成主义蒙太奇 · Constructivist Montage

> 收录自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（LemoLab，commit `f171360`）· 分类：剪辑与纪实（Edit & Documentary）

**一句话**：帝国大厦的小册子写着建造者，工地实拍和老照片给出答案：每天 2,500 人。（The Empire State's 1931 brochure credits its builders; the site film and Hine's photos answer: 2,500 a day.）

**适合**：Industry histories · Milestones · Collective effort

## 文件
- [`STYLE.md`](STYLE.md)：风格提示词原文——**选了这个风格就按它做**（本质与边界、材质、配色逻辑、字体与字幕、动效、镜头语法、声音、原生手法、媒介的坑、变化空间）。
- [`DEMO.md`](DEMO.md)：上游样片《410 Days》（60 s）的说明，只是一个例子，不要照搬它的故事、镜头和时间。
- `style.ts`：参考色板与字体（风格库现有字段）。**色板只是参考**：片子用这个风格时，配色由模型按片子的需要、照 STYLE.md 的配色逻辑自己定。
- `refs/poster.jpg`、`refs/frame.jpg`：样片海报帧和画廊关键帧。
- 样片源码（Canvas / WebGL 页面 + 配乐混音脚本 + 字体）：`vw style demo kino-montage` 取到 `out/styles/kino-montage/demo/`，读来学手法，不在本工程里渲。
