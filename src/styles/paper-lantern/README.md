# 纸雕灯影 · Paper-cut Lightbox

> 收录自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（LemoLab，commit `f171360`）· 分类：东方传统（East Asian Traditions）

**一句话**：一枚月饼讲中秋的团圆与思念，纸雕灯箱层层透光。（A single mooncake tells the Mid-Autumn story of reunion and longing inside a glowing paper-cut lightbox.）

**适合**：Festivals · Gift brands · Cultural stories

## 文件
- [`STYLE.md`](STYLE.md)：风格提示词原文——**选了这个风格就按它做**（本质与边界、材质、配色逻辑、字体与字幕、动效、镜头语法、声音、原生手法、媒介的坑、变化空间）。
- [`DEMO.md`](DEMO.md)：上游样片《A Mooncake's Longing》（121.8 s）的说明，只是一个例子，不要照搬它的故事、镜头和时间。
- `style.ts`：参考色板与字体（风格库现有字段）。**色板只是参考**：片子用这个风格时，配色由模型按片子的需要、照 STYLE.md 的配色逻辑自己定。
- `refs/poster.jpg`、`refs/frame.jpg`：样片海报帧和画廊关键帧。
- 样片源码（Canvas / WebGL 页面 + 配乐混音脚本 + 字体）：`vw style demo paper-lantern` 取到 `out/styles/paper-lantern/demo/`，读来学手法，不在本工程里渲。
