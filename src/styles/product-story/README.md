# 暖纸产品叙事 · Warm-paper Product Story（product-story）

> 从空白开始，技法借自 活体实机录屏（living-screencast）；基准作品 `loomcare.mp4`。2026-10-27 用户认可后进库。

**一句话**：暖白纸面上讲「我们做了什么、它怎么工作、结果如何」——真实感的产品界面和单据是主角，章节之间插一镜暗场电影感，结尾一排大数字。

**适合**：企业内向上汇报 · 项目演示（结合具体项目的 mock 演示）· 产品内部讲解 · 系统上线复盘

**用来做**：横屏 1920×1080，30 秒到 5 分钟；没有口播（要口播先问）。

## 文件
- `STYLE.md`：完整的风格说明（选了这个风格就按它做）。
- `CHANGES.md`：相对技法底子和原来的图纸风格改了什么、为什么。
- `style.ts`：参考色板与字体（色值取自基准作品的画面）。
- `refs/poster.jpg`：样片海报帧（总览页用它当封面）；`refs/styleframe.png`：风格帧（用本工程的代码渲的，样片 14.4s 那一屏）。
- `refs/ref-*.jpg`：基准作品的 8 帧（开场微距、暗场金色线框、界面识别、聚光单据、规则卡片、手机双出口、3D 白色条形、数字墙）。
- `refs/demo.mp4`：样片 = 基准作品 `loomcare.mp4`（软链到仓库根目录的原片，4 分 47 秒；总览页里直接播）。只是一个例子，不照搬它的故事、镜头和时间。
- 工坊样片：`src/films/product-story-test/`（29.5 秒，虚构的售后工单助手；CHANGES 每一行都在画面里出现）。

## 基准作品实测（loomcare.mp4，287 秒）
- 结构：开场一个人的一件事（8 页纸）→ 01–07 编号章节（读懂、指引、反馈、底座…）→ 数字墙 → logo 落版。
- 画面：暖白纸面约占 80%，暗场插叙（金色线框、聚光单据、点阵光、光点时间线）约 15%；112 处切换，动作段中位 0.77 秒；静止 38% / 细微 28% / 明显 23% / 大幅 11%。
- 声音：没有口播（Whisper 前 90 秒没听到人声）；配乐节拍感弱（周期相关 0.36，约 100–110 BPM），偏氛围；响度 −23.8 LUFS、LRA 6.9；低频比中频高 1.9 dB（偏厚）。

## 和原来的图纸（blueprint）的区别
图纸是工程图：图框、点阵网格、只用细线、不要卡片和阴影，适合架构 / 链路 / 迁移这类「讲结构」的片。本风格是产品叙事：界面卡片、单据实物、暗场插叙，适合「讲一个系统怎么帮人把事办成」的演示片。图纸保留在库里，两者分开用。
