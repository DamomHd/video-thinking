# 改了什么

从空白开始，技法底子是 活体实机录屏（living-screencast）；同时对照我们原来的 图纸（blueprint），说明为什么不再用它做这类片子。

| 节 | 原来 | 现在 | 为什么 | 分组 |
|---|---|---|---|---|
| 本质 | 底子：真实产品界面 + 像素吉祥物；图纸：工程图（图框、点阵网格、细线） | 暖白纸面上的产品叙事：一个人的一件事开头，真实感界面和单据是主角，章节间插暗场电影感一镜 | 基准作品 loomcare 的做法；汇报 / 项目演示要「看得见它在工作」，工程图的冷和吉祥物的萌都不对 | — |
| 材质 | 底子：像素吉祥物；图纸：禁止圆角卡片和阴影 | 去掉吉祥物；允许圆角 10–14px + 极浅阴影（≤ 8%）的卡片；加真实感单据、微距纸面、暗场线框 | 产品界面本来就是卡片；关键是克制，不是禁止 | 一改就变味 |
| 配色 | 图纸：黑灰白 + 一个强调色 | 中性为主 + 一个状态色族（荧光笔黄 / 命中橙 / 通过绿，各司其职）+ 暗场只有金光 | 演示里要表达「识别出问题 / 已通过」，一个强调色不够；用规则约束数量 | 一改就变味 |
| 字体 | 图纸：标题 + 大量等宽注释 | 编号 + 粗黑结论句 + 灰副句；引语用宋体；大数字细字重 | 基准作品的版式；等宽只留给编号、单号、规则号 | 放心改 |
| 动效 | 底子：界面里的吉祥物带动作 | 镜头慢、界面快；界面动作都是真动作（打字、流式、落定、勾选、计数） | 演示的可信来自「真的在跑」 | 放心改 |
| 镜头 | — | 纸面微距、界面推进、虚化叠大字、单据横移、双出口并排、暗场插叙、数字墙 | 基准作品的镜头词汇 | 一改就变味 |
| 声音 | 底子：hi-fi 乐队 + 芯片音 | 室内乐采样配乐（钢琴、竖琴、拨弦、轻弦），无口播；暗场换低频长音 + 一次重拍 | 基准作品没有口播、配乐安静；暗场要有重量 | 放心改 |
| 原生手法 | 底子：吉祥物系列 | 纸到界面、一句话走完整流程、原文永远在旁边、挂起来的证据、暗场一亮、同一份画像两个出口、数字墙 | 这类片子的高光时刻 | 放心改 |
