# 卫星简报 · Satellite Briefing

> 收录自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（LemoLab，commit `f171360`）· 分类：实证影像（Evidence Films）

**一句话**：卫星照着地图去找咸海，找到的是沙漠；只有筑了坝的那一块回来了。（A satellite follows the map to the Aral Sea and finds a desert; only the part someone dammed came back.）

**适合**：Climate · News explainers · Geography

## 文件
- [`STYLE.md`](STYLE.md)：风格提示词原文——**选了这个风格就按它做**（本质与边界、材质、配色逻辑、字体与字幕、动效、镜头语法、声音、原生手法、媒介的坑、变化空间）。
- [`DEMO.md`](DEMO.md)：上游样片《The Map Still Says Sea》（37.8 s）的说明，只是一个例子，不要照搬它的故事、镜头和时间。
- `style.ts`：参考色板与字体（风格库现有字段）。**色板只是参考**：片子用这个风格时，配色由模型按片子的需要、照 STYLE.md 的配色逻辑自己定。
- `refs/poster.jpg`、`refs/frame.jpg`：样片海报帧和画廊关键帧。
- 样片源码（Canvas / WebGL 页面 + 配乐混音脚本 + 字体）：`vw style demo satellite-briefing` 取到 `out/styles/satellite-briefing/demo/`，读来学手法，不在本工程里渲。
