# 60s 间谍片头 · 60s Spy Title Sequence

> 收录自 [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar)（LemoLab，commit `f171360`）· 分类：图形与排版（Graphic & Type）

**一句话**：虚构 1964 年间谍片的片头：追一把被偷的钥匙，几何碎片最后拼成片名。（Opening titles for an imaginary 1964 spy film: a chase for a stolen key until the shapes lock into the title.）

**适合**：Title sequences · Event openers · Trailers

## 文件
- [`STYLE.md`](STYLE.md)：风格提示词原文——**选了这个风格就按它做**（本质与边界、材质、配色逻辑、字体与字幕、动效、镜头语法、声音、原生手法、媒介的坑、变化空间）。
- [`DEMO.md`](DEMO.md)：上游样片《The Velvet Cipher》（44.1 s）的说明，只是一个例子，不要照搬它的故事、镜头和时间。
- `style.ts`：参考色板与字体（风格库现有字段）。**色板只是参考**：片子用这个风格时，配色由模型按片子的需要、照 STYLE.md 的配色逻辑自己定。
- `refs/poster.jpg`、`refs/frame.jpg`：样片海报帧和画廊关键帧。
- 样片源码（Canvas / WebGL 页面 + 配乐混音脚本 + 字体）：`vw style demo spy-titles` 取到 `out/styles/spy-titles/demo/`，读来学手法，不在本工程里渲。
