# 分镜 · iDo Space 小红书宣传片

> 6 镜，50 秒，竖屏 1080×1920，30fps

---

## S1 开场提问（0–5s）

**时长**：5 秒  
**画面**：
- 黑底渐亮（深紫色 #1A1A2E）
- 问句文字逐行浮现（SF Pro Rounded，细体，白色，居中）
  - 行 1："你记录过运动、睡眠、情绪"（1s 显示）
  - 行 2："但你了解自己的亲密状态吗？"（2s 显示，稍大）
- 文字淡入 + 轻微上浮（ease-out）

**镜头**：静止  
**声音**：
- 环境音起（低频 pad，温暖）
- 无音效

**情绪**：克制、提问、不评判

---

## S2 记录层 · 日历（5–13s）

**时长**：8 秒  
**画面**：
- APP 主界面截图（`01_home.png`）
- 镜头从远推近（zoom: 0.8 → 1.2）
- 日历上的日期标记逐个亮起（粉色小点，按节拍）
- 3s 时点击一个日期，记录卡片从下方浮起（玻璃态毛玻璃，有阴影）
- 卡片内容：时间、时长滑块、心率（模糊处理敏感字段）

**镜头**：push（缓推）  
**声音**：
- 日期标记亮起：轻柔的"滴"（每个 0.5s）
- 点击音效：柔和的"咚"（低频）
- 卡片浮起：玻璃滑动音（200ms）
- 字幕（toast）："像记日记一样简单"

---

## S3 数据可视化 · 频率图（13–21s）

**时长**：8 秒  
**画面**：
- 统计页面截图（`02_stats.png`）
- 切到频率柱状图特写（浅景深，背景虚化）
- 柱子逐个从底部长高（周一 → 周日，每根 1s）
  - 最高的柱子（周四，8 次）有轻微发光
- 右上角大数字"14 次"跳动显示（Inter Tight 600，粉橙渐变）

**镜头**：特写（zoom: 1.5），镜头微微右移（跟随柱子生长）  
**声音**：
- 柱子长高：低频"嗡"（合成器，音高随高度升高）
- 数字跳动：快速"滴答滴答"（0.3s 滚动完成）
- 最高柱子发光时：一声轻柔的"叮"

---

## S4 数据可视化 · 时长分布（21–30s）

**时长**：9 秒  
**画面**：
- 持续时间卡片特写（`02_stats.png` 下半部分）
- 时长滑块从左向右滑动（3 分 → 18 分，显示平均值）
- 下方分布曲线逐渐绘制（粉色渐变填充）
- 29.5s：配乐高潮，曲线填满，整个卡片微微震动（2 帧）

**镜头**：glide（平推，从左到右）  
**声音**：
- 滑块滑动：持续的"唦唦"（150ms 一次，共 6 次）
- 曲线绘制：轻柔的"刷"（笔刷音）
- **高潮（29.5s）**：
  - 配乐爆发（鼓点 + 和弦）
  - 重击音效："嘭"（低频 + 玻璃碎裂泛音）
  - 卡片震动音：短促的"砰"

---

## S5 隐私层 · 锁与保护（30–45s）

**时长**：15 秒  
**画面**：
- 从数据页淡出到黑底
- 锁图标从小到大推近（Z 轴，从远景到特写）
  - 锁是玻璃质感，边缘有彩虹色散（类似 glass-product）
- 锁定格在画面中央（35s）
- "本地存储"四个字逐字浮现在锁下方（SF Pro，细体，白色）
- Face ID 图标在锁右上角闪烁（1 次，38s）
- 背景：深紫色渐变，顶部有柔和的光晕

**镜头**：push → still（推近后静止）  
**声音**：
- 锁推近：低频"隆隆"（逐渐靠近感）
- 锁落定：机械的"咔哒"（金属 + 玻璃共鸣）
- 文字浮现：轻柔的"唰唰唰唰"（每字 0.3s）
- Face ID 闪烁：短促的"嘀"（高频，像扫描）
- 字幕："你的数据，只属于你"

---

## S6 行动召唤 · 下载（45–50s）

**时长**：5 秒  
**画面**：
- 锁淡出
- APP icon 居中显示（iDo Space 的真实 icon）
- 产品名"iDo Space"在 icon 下方（SF Pro Rounded，中等粗细，白色）
- Slogan："理解自己，从记录开始"（小字，灰色，Inter）
- 下方：App Store / Google Play 下载图标（小，不抢眼）
- 背景：深紫色渐变，底部有微光扫过

**镜头**：静止  
**声音**：
- APP icon 落定：玻璃轻触音"叮"
- 配乐渐弱（最后一小节）
- 片尾和弦：C 大调主和弦（钢琴 + pad，温暖）
- 无字幕（画面文字足够清晰）

---

## 转场

- **S1 → S2**：淡入淡出（0.5s）
- **S2 → S3**：硬切（在节拍上）
- **S3 → S4**：glide 连续（镜头不停，画面切换）
- **S4 → S5**：淡出到黑（1s）
- **S5 → S6**：溶解（0.8s，锁淡出，icon 淡入）

## 技术备注

### 玻璃态效果
```css
backdrop-filter: blur(20px) brightness(1.1);
background: rgba(255, 255, 255, 0.1);
border: 1px solid rgba(255, 255, 255, 0.2);
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);
```

### 浅景深模拟
```css
filter: blur(8px); /* 背景 */
```

### 数字滚动
```typescript
const count = interpolate(frame, [startFrame, endFrame], [0, 14], {
  easing: Easing.out(Easing.exp),
});
Math.floor(count); // 显示整数
```

### 锁图标推近（Z 轴）
```typescript
const scale = interpolate(frame, [startFrame, endFrame], [0.3, 1.5], {
  easing: Easing.out(Easing.quad),
});
transform: `scale(${scale})`;
```
