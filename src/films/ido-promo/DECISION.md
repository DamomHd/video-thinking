## 1. 内容策划

### 一句话
iDo Space 是你的私密追踪工具，记录、理解、保护你的亲密状态。

### 核心信息（50 秒）
1. **记录很简单**（0–8s）：日历 + 卡片，像记日记一样
2. **数据有洞察**（8–30s）：频率、时长、偏好模式，你看见自己不曾注意的部分
3. **隐私有保障**（30–45s）：本地存储、Face ID、你的数据只属于你
4. **行动召唤**（45–50s）：下载 iDo Space，开始记录

### 受众带走什么
"这个 APP 能帮我理解自己的身体和亲密状态，而且很安全、不会泄露隐私。"

### 删掉的内容与理由
- ❌ 具体标签字段（姿势、射精位置等）—— 太细节，让视频变成"功能说明书"，且小红书审核风险高
- ❌ 多伴侣场景 —— 审核风险
- ❌ 游戏化元素（骰子、飞行棋）—— 和核心价值"自我觉察"无关
- ❌ Apple Health 同步 —— 技术细节，不是核心卖点
- ❌ "提升性生活质量"等暗示性文案 —— 避免擦边

### 结论出现时刻
45s（最后 5 秒行动召唤）

## 2. 视觉方向

### 风格选择
**自定义主题**（不选风格库）

理由：
- 风格库里没有匹配的类别（glass-product 是 3D 实物，dark-keynote 是代码画的 UI 组件）
- **需要展示真实 APP 界面**（用户要看到"就是这个样子"），不是重新设计
- 按经验 #11："风格库默认不选、事后沉淀" —— 做完后如果用户认可，再用 `vw style save` 进库
- 自定义方向：真实 UI 截图 + 玻璃态强化 + 浅景深 + 光扫动效

### 视觉语言
- **真实性优先**：直接用 APP 截图，不重绘 UI
- **玻璃态强化**：`backdrop-filter: blur()` + 边缘高光 + 渐变反光
- **景深**：模糊背景，突出前景卡片
- **配色**：APP 原生的深紫 (#1A1A2E) + 粉橙渐变 (#FF6B9D → #FFA06B)
- **光**：柔和的顶光扫 + 卡片落定时的微光

### 镜头语言
**舞台推进**（glass-product 自带的推推镜 + 浅景深特写）
- 开场：从远到近推向日历
- 中段：UI 卡片逐个浮起（Z 轴深度）
- 尾段：锁图标特写

不用 3D 漫游（功能展示不需要空间叙事）

### 关键设计决策
1. **真实 UI vs 重设计**：直接用 APP 截图（用户看到的就是真实的），但加玻璃材质和景深强化质感
2. **配色**：沿用 APP 的深紫 + 粉橙渐变，玻璃反光用冷色调（蓝白）制造对比
3. **文字处理**：不用口播，关键信息用屏幕字（SF Pro 圆角，和 iOS 一致）

## 3. 声音设计

### 配乐
**氛围钢琴 + pad**（Freesound / 本地采样）
- 速度：80–100 BPM（不要太快，给思考空间）
- 情绪：温暖、私密、向上
- 高潮位置：30s（数据洞察段的结尾）

### 音效层次
- **UI 交互**：轻柔点击、滑动、卡片浮起
- **数据变化**：数字滚动的"长音"（合成器 pad）
- **关键时刻**：锁图标落定时的"咔哒"

### 静默
- 8s（"记录很简单"结束，给信息落地）
- 30s（数据段结束，转向隐私）

## 6. 验收标准

### 守门（vw check）
- [ ] 确定性：无 `Math.random()`、CSS 动画
- [ ] 时间：幕表总长 50s
- [ ] 声音：所有动作事件都有配声或写 silent 理由
- [ ] 颜色：写死的颜色不超过 3 处（玻璃反光）

### 设计评审（vw review 提示 + taste.md）
- [ ] 高级感：玻璃材质 + 景深 + 真实 UI
- [ ] 克制：无粉红、桃心、床单元素
- [ ] 呼吸感：两处静默，不是鬼畜剪辑
- [ ] 信息清晰：每段只讲一件事

### 声音评审
- [ ] 至少两处真静默（✓ 8s / 30s）
- [ ] 至少两个段落由声音带过去（S2→S3 / S4→S5）
- [ ] 人声比配乐高 10 dB（无口播，跳过）

## 7. 技术路线

### 画面
- **UI 截图**：从 `/Users/sneaker/Desktop/project/intimamate/screenshots/zh/` 取
- **玻璃效果**：CSS `backdrop-filter: blur()` + 边缘高光
- **景深**：`filter: blur()` 模拟浅景深
- **数字动画**：`interpolate()` 滚动

### 声音
- **配乐**：`vw music match --source=freesound --local --bpm=80-100`
- **音效**：`vw sfx search --source=freesound` 或 Kenney 包
- **事件表**：写在 `audio/adapter.ts` 的 `events()`

### 渲染
- 竖屏 1080×1920，30fps
- 不开超采样（Intel 机器）
- `vw render ido-promo --mode=final`
