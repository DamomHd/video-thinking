# 导演决策单 · product-story 风格样片（product-story-test，29.5s）

> 这是风格工坊的样片（`docs/method/style-workshop.md` §5），任务是证明草稿 `out/style-drafts/product-story/` 这个风格成立，不是正式制作。题材是虚构的「售后工单助手」，数据都是假的。
> 开工前读了：草稿的 STYLE.md / CHANGES.md、基准作品 `loomcare.mp4` 的分析（`out/ref/loomcare/`）、`docs/method/taste.md`。

## 开工前问答
- 问了什么、用户怎么答：用户要求把 loomcare.mp4 的样子沉淀成自己的风格，并且「保证整体风格库的规范统一」→ 按风格工坊走完：风格帧 → 样片 → 用户点头再 keep。时长 29.5 秒（工坊要求 15–30 秒；首版 25.5 秒读字不够，拉长了开场和数字墙）；风格 = 草稿 product-story；无口播、无字幕（风格本身没有口播，工坊缺省也没有）；不出分镜、只出一个结构（工坊规定）。

## 标杆
- 标杆是哪一两部、为什么是它：`loomcare.mp4`（用户指定的基准作品，「整体流程我很满意」）。
- 学什么：一个人的一件事开头、真实感界面当主角、编号 + 结论句 + 灰副句的版式、暗场金色插叙、数字墙收尾、室内乐无口播。
- 不拿什么：它的故事（病历 / 孕产）、具体界面、logo、文案；样片换成售后工单题材。

## 内容与观众
- 讲给谁、他们看完要记住哪一句话：看风格的人（用户本人）。片内的那句话：「判断交给规则，确认留给人。」
- 素材里最有力的三个事实：一句话走完四步；系统识别出「质检超时 2 天」并留给人；42 条规则 / 3 个写动作要确认 / 128 张测试工单全过。
- 讲法：开场是故事；界面段是展示 + 流程；暗场是机制；数字墙是证据。

## 风格与方向
- 本片主题：沿用风格草稿 `product-story`（还没进库，所以 theme.ts 先手写同一套色值；进库后改成 `extendStyle(PRODUCT_STORY, {})`）。
- 参考够不够：够（基准作品）。
- 这部片的样子和「房子风格」差在哪：不是图纸（没有图框和点阵网格），也不是全黑科技风；暖白纸面 + 真实感界面 + 一镜暗场。

## 语言与结构
- 三个候选结构：工坊规定样片只出一个结构 → 「一张单子 → 一句话走完流程 → 暗场看见系统 → 数字墙」，正好把 CHANGES 的每一行和四个原生手法各走一遍。
- 每段：故事 → 纸面微距；展示 → 界面演示；机制 → 暗场线框；证据 → 数字墙。细节：
  1. 一张单子（0–7s）故事 → 纸面微距：镜头贴着售后单，浅景深，荧光笔划过「质检未完成，退款暂缓」，标题「退货那天，她打了第三次电话。」
  2. 一句话走完流程（7–15s）展示 → 那句话飞出纸面，落成工单摘要（**纸到界面**）；打字、发送、流式回复、四步逐张落定、第 3 步命中橙、进度走到 91%（**一句话，走完整流程**）。
  3. 暗场一亮（15–20.5s，占全片 19%）机制 → 纸面暗下，金线底板画出、能力块亮起、光柱升起、光点点亮，两个标注（**暗场一亮**；首版四个标注读不完，删到两个）。
  4. 数字墙（20.5–29.5s）证据 → 四行逐行落定，收束句 + 128 格亮成通过绿（**数字墙**）。
- 脊梁：「质检未完成，退款暂缓」这句话——从纸上到界面摘要，到第 3 步的问题，到数字墙里「确认留给人」。
- 主镜头：**否**（指 2D↔3D 镜头桥那种主镜头）。暗场那一镜用了 three（金线框、辉光、景深），是风格规定的「暗场插叙」，不是主镜头；15–30 秒的风格样片再加镜头桥会把重点从「风格」移到「技法」。
- 连续性链条：荧光笔那句 → 飞到界面 → 界面暗下 → 金光 → 亮回纸面 → 数字墙。
- 镜头表：微距慢横移（贴纸，看清那一行）→ 界面整体缓推 6%（镜头慢、界面快）→ 暗场缓慢绕转、略推近（重量感）→ 数字墙整版缓推 4%（让数字读完，又不死）。

## 节奏
- 路线：continuous，没有硬切；100 BPM（`vw music match --bpm=100-112`，按风格规定的速度范围拟合画面拍点）。能量：开场安静 → 四步落定一拍一张 → 暗场前抽空半小节、光点点亮（第二高潮）→ 数字墙逐行 → 收束（主高潮）。
- 关键段的 read 表：开场标题 2.4–5.9s；界面结论句 7.1–15s；第 3 步问题约 11–15s；暗场标注约 17.2–20.5s（两个）；数字墙每行 ≥ 4s；收束句 26.9–29.5s。
- 逐秒节拍表 / 拍点图：见 `world/layout.ts` 的 K 表和 BEATS（四步、四个标注踩拍，数字行隔拍）。

## 声音
- 配乐来源与理由：`vw music match --local --sampled=chamber`（风格 STYLE.md「声音」：室内乐采样，安静温和，无口播）。
- 重拍：第 3 步「发现问题」（stamp，heavy）、光点点亮（hero）、收束（hero）。
- 留白：开场标题（开场第一句留白）、流式回复（紧接四步序列）、纸面暗下（暗场前的短静默）、亮回纸面（靠配乐回落）。
- 底噪：分层合成 room-tone。
- 成组入场：四步、两个标注、四行数字落定，音高按配乐调走（pluck）。
- 素材来源：全部分层合成（本地），没有外部素材。
- 配乐音色：chamber。
- 口播：无。
- 中段「静 → 爆」：`cue.climax2` 指向光点点亮（K.ignite）。
- 声音设计表：纸面（底噪 + 荧光笔气声 + 形变滑音）/ 界面（打字计数颗粒 + 发送 + 四声落定）/ 暗场（吸气 + 重拍）/ 数字墙（四声落定 + 收束重拍）。
- 静默与声音转场：暗场前（作曲静默半小节）、开场第一句。

## 质感
- 空间与层次：纸面微距用 CSS 透视 + 逐行景深模糊；界面卡片 1px 描边 + 6% 阴影；暗场 three：金线框、辉光、景深、微尘、暗角、颗粒。字号：标题 58 / 52 / 44，副句 19–21，大数 64 细体，界面 14–17。
- 冲击力：暗场光点点亮那一下（静默 → 闪光 + 辉光冲高 + 重拍）。
