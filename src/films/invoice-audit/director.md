# 导演决策单 · 报销台（虚构产品演示）

> 由模型在动手前写出。沿用风格库 `product-story`（暖纸产品叙事）。开工前依次读：`vw learn` → `docs/method/taste.md` → `docs/library/README.md` → `docs/capabilities.md` → `src/styles/product-story/STYLE.md`。
> 片子 id 沿用 `invoice-audit`（脚手架名，不再改），title 是「报销台」。

## 开工前问答

- 讲法：**机制 + 证据**（一个人的一件事被系统接住的过程），不是主张、不是清单。
- 受众：企业财务 / HR / 审批负责人。看完决定要不要用自动化审批替掉手工核报销。
- 时长：**32.0 秒**（@60fps，1920×1080）。
- 语言：简体中文。
- 风格：**沿用风格库 `product-story`**（高度复刻：暖白纸面、真实感界面与单据、暗场金色线框插叙、结尾数字墙、七种原生手法）。理由：用户明确要求"整体风格高度复刻 product 那个"。
- 参考够不够：够。product-story 的 STYLE.md + 样片 `product-story-test` + 基准作品 `loomcare.mp4` 参考帧都在库里。
- 口播：**要口播**（用户确认）。中文用 edge-tts（需联网）。口播改了信息容量（中文约 4 字/秒、留 15% 静默），节奏按口播重排。
- 用户自己的素材：无（虚构产品，界面与单据都按真实比例画、mock 数据写得像真的但不涉真实敏感数据）。
- 要不要先看分镜：**不要**（用户未要求），直接做。

## 内容策划

> **先于标杆、风格和画面**。product-story 风格装得下一个"系统怎么帮一个人把事办成"的故事，本片把它用满七种原生手法。

- 讲给谁、他们看完要做什么决定：讲给被月底报销核单拖住的财务负责人；看完决定用自动化审批替掉手工核报销。
- 一句话（看完必须记住的结论，判断句）：**报销台替小林把 8,600 份报销一份份接住，超标零误判。**
- 讲法：故事 + 机制（一个人的一件事 → 系统一步步接住 → 结果数字）。
- 事实清单（虚构但写得像真的，单号 / 时间 / 金额 / 状态齐全，不涉真实敏感数据）：
  - 主人公：员工小林，出差回来报销。
  - 触发事件：住宿费发票 ¥1,200，差旅标准 ¥1,000，超了 ¥200。
  - 系统动作：识别 → 比对标准 → 定位超标行 → 生成审批意见，每步一张卡落定。
  - 原文永远在旁边：每个结论连一根细线回到报销单 / 发票那一行。
  - 规模：月底共 8,600 份报销。
  - 结果：124 处超标、0 误判、31 秒完成。
- 信息容量（vw brief 验证）：32 秒 × 0.85 ≈ 27 秒可讲，中文 4 字/秒 ≈ 108 字。设 1 个结论 + 3 个支撑 + 各自证据，5 个读点，每读点 5–6 秒，从容。
- 取舍（删了什么、为什么）：
  - 删"产品功能三件套罗列"——风格第 9 节点名这是 PPT 套路；功能融进"一句话走完流程"那一段。
  - 删多主人公——product-story 是"一个人的一件事"，只留小林。
  - 删真实企业名 / 真实单号——虚构，mock 数据。
  - 暗场只插一次（≤8 秒、≤20%）——风格第 1、9 节硬约束。
- 纸面检验（只读口播 + 屏幕字能不能讲通一句话）：小林出差报销 → 住宿超了 ¥200 → 报销台识别比对定位生成审批 → 8,600 份接住、124 处超标、零误判、31 秒。首尾呼应"一份份接住"，讲得通。

## 标杆

> 不用库里风格的样片当标杆。product-story 的标杆是 `loomcare.mp4`（基准作品，只学技法不照搬）。

- 标杆是哪一两部、为什么是它：
  - `loomcare.mp4`（product-story 基准作品，4 分 47 秒）——学它"一个人的一件事 → 编号章节 → 暗场插叙 → 数字墙"的骨架，和暖白纸面 / 暗场金色光的对比节奏。
  - Linear 2024 发布片——学它"界面是真实在工作的"那种干净克制。
- 学什么：暖白纸面占比 80%、暗场 15% 的比例分配；界面动作快、镜头慢的对比；大数字常规字重不加粗。
- 不拿什么：不照搬 loomcare 的具体章节文案、具体单据类型、具体人物；不借 Linear 的 UI 元素。本片是虚构的报销审批场景。

## 风格与方向

- 本片主题：**沿用 `product-story`**。theme.ts 直接 `extendStyle(PRODUCT_STORY, {})`，不改色板（高度复刻）。
- 参考够不够：够（STYLE.md + 样片 + 基准帧都在库里）。不需出三个方向。
- 这部片的样子和「房子风格」差在哪：product-story 不是"房子风格"（它是库里自有风格）。本片高度复刻它，差在内容（报销审批 vs 售后工单 / loomcare 的医疗场景）——故事、人物、行业、单据类型、数字墙的具体数字全是本片自己的，见「和样片对照」。

## 语言与结构

- 三个候选结构，选哪个、为什么：
  1. **一段旅程（选）**：小林的一份报销 → 系统接住 → 数字墙收束。最贴合 product-story"一个人的一件事"内核。
  2. 前后对比（手工 vs 自动）：会变成 product-story 第 1 节点名的"不是品牌广告片"那种对比套路，删。
  3. 倒计时（31 秒审批）：把数字前置会剧透结论，删。
- 每段：讲法 → 语言 → 主体形态：
  - 01 一份报销：故事 → 纸面微距 + 荧光笔划过 → 报销单 + 发票原件（纸到界面原生手法）。
  - 02 一句话走完流程：机制 → 界面流式出字 + 卡片落定 + 原文连线 → 报销台界面（一句话走完流程原生手法 + 原文永远在旁边）。
  - 03 暗场一亮：机制 → 暗场金色线框 → 报销规则引擎能力板（暗场一亮原生手法）。
  - 04 两个出口：机制 → 后台审批卡 + 手机推送同源 → 双设备并排（同一份画像两个出口原生手法）。
  - 05 数字墙：证据 → 一排大数字 + 细线图示 → 8,600 / 124 / 0 / 31（数字墙原生手法 + 落版）。
- 脊梁：那张被荧光笔划过的报销单超标行，从第 01 段的纸面原件，变成第 02 段界面里的超标字段，第 03 段在暗场里被金色线框标出，第 04 段化为手机上的审批推送，第 05 段收成数字墙里"8,600 份"那一个数。
- 主镜头：**否**。理由：product-story 是纸面 + 界面 + 短暗场插叙，不做 3D 主镜头漫游；暗场用 FilmCanvas + FilmPost 的景深 / 辉光 / 颗粒就够了，不需要 Blender 机身（本机 Intel CPU 渲一帧 11–20s，不值当）。
- 连续性链条：01 荧光笔划超标行 → 02 那个超标金额飞成界面字段 → 02 原文连线 → 03 连线化为暗场金色线框 → 03 线框收成 04 手机上的一条推送 → 04 推送计进 05 的 8,600。
- 镜头表（景别 / 角度 / 运镜 / 时长 / 承载信息点 / 为什么）：
  - 01（0–7s）：微距，平视，缓推贴到超标行。承载"超 ¥200"。为什么：product-story 开场原生手法"纸面微距 + 荧光笔"。
  - 02（7–16s）：中景俯视界面，缓推到审批卡。承载"识别→比对→定位→审批"。为什么：界面是真实在工作的，镜头只缓推不抢。
  - 03（16–21s）：暗场，缓拉远看能力线框。承载"报销规则引擎"。为什么：暗场插叙动作更慢更有重量（STYLE §5）。
  - 04（21–27s）：中景，后台审批卡与手机并排，轻微横移。承载"同源同秒"。为什么：两个出口并排是原生手法。
  - 05（27–32s）：定格，数字从上到下落定。承载结论数字。为什么：数字墙收束。

## 节奏

- 路线：continuous（缓推 / 漂 / 平移为主，段间亮度过渡不硬切）。BPM：**104**（product-story §7 配乐 100–112 BPM）。能量曲线：钩子在 3s（荧光笔划过）、蓄力在 12s（审批卡落定）、第一释放 16s（原文连线亮起）、暗场 18s 收一口气、第二释放 28s（数字墙落定）。
- 配乐路线：**画面先行**（`audio/score.ts` + `vw music score`，`grid.lock: false` + `g.hit(id)` 贴着画面拍点）。为什么：product-story §7 配乐要"安静、温和、偏室内乐、节拍感不强"，画面先行让音乐贴着界面动作的落点走，不拉伸。
  - 调性：F 大调（暖、稳定），和声 vi–IV–I–V 循环。
  - 动机：一个两音的上行小三度（模仿"接住"的动作），在 01 现一次、02 流程走完时回一次、05 数字墙落定时升一个八度回来。
  - 配器：拨弦 + 竖琴（"接住"的质感）+ 轻弦乐铺底；暗场 03 段换低频长音 + 钟琴单音 + 一次重拍（`cue.climax2` 指向 18s 这次暗场重拍，作曲前面静默半小节）。
- 关键段的 read 表（一次只读一件）：
  - 0–4s：读懂"月底小林要报 8,600 份"。
  - 4–7s：看清"住宿超了 ¥200"。
  - 8–13s：看清"识别→比对→定位→审批"四步。
  - 14–16s：看清"超标行第 8 行 超 ¥200"。
  - 18–21s：感受暗场规则引擎（不读字，看形象）。
  - 22–26s：看清"后台 + 手机同源同秒"。
  - 28–31s：看清"8,600 / 124 / 0 / 31"四个数字。
- 逐秒节拍表：
  - 0s 暖白纸面亮起；1.5s 报销单 + 发票原件微距推近；3s 荧光笔划过超标行；4.5s "超 ¥200"飞出；6.5s 切到报销台界面。
  - 7.5s 输入框光标；8.5s 流式出"识别"卡；10s "比对"卡落定；11.5s "定位"卡 + 原文连线亮；13.5s "审批"卡。
  - 16s 纸面暗下去；17s 暗场金色线框亮起；18.5s 重拍（climax2）；20s 线框收。
  - 21s 回到纸面；21.5s 后台审批卡 + 手机推送同时落；24s 连线亮；26s 审批已推送。
  - 27s 数字墙起；28s "8,600"落定；29s "124"落定；30s "0"落定；30.5s "31秒"落定；31s logo 落版。
- 拍点图：104 BPM，4/4，每幕对齐小节。01 = 3 小节、02 = 4 小节、03 = 2.5 小节（含半小节静默）、04 = 2.5 小节、05 = 2 小节。荧光笔划过（3s）、四张卡落定（8.5/10/11.5/13.5s）、原文连线亮（11.5s）、暗场重拍（18.5s）、双出口同落（21.5s）、四个数字落定（28/29/30/30.5s）全落在拍上。

## 声音

- 配乐来源与理由：本片原创作曲（`audio/score.ts` + `vw music score`），画面先行。不用 `vw music match --local`（通用模板每部片同一首，`vw review` 会报警）。
- 重拍：18.5s 暗场重拍（`cue.climax2`，前面静默半小节）；28s 数字墙第一数字落定（hero-hit）。
- 留白：开场第一句前（0–1.5s 只有纸面亮起的声音）、暗场前（15.5–16s）、数字墙前（26.5–27s）各一次短静默。
- 底噪：极轻的室内环境底（空调低频 + 偶尔纸张声），全程 −40 dB 以下。
- 质感床（`sectionBeds`，跟着情绪换）：
  - 01 纸面微距：`texture-bed, warm`（暖纸的安静）。
  - 02 界面流程：`texture-bed, air`（界面在工作的轻盈空气感）。
  - 03 暗场：`texture-bed, low`（低频长音，切到暗场）。
  - 04 两个出口：`texture-bed, glass`（双设备同源的清透）。
  - 05 数字墙：`texture-bed, tension`（结论前的张力，落定后转 warm 收）。
- 成组入场踩拍：四张卡（识别 / 比对 / 定位 / 审批）按 F 大调音阶上行落定（F→A→C→F），用 marimba 音色。四个数字按四度上行（F→Bb→F→F 高八度），pluck 音色。
- 素材来源：本地合成（`--local`），分层音色（`layered` + 角色词 card-land / count-tick / reveal-swell / focus-air / stamp / hero-hit）。
- 配乐音色：采样配器 `chamber`（室内乐，product-story §7 指定）。
- 口播：声音 edge-tts 中文女声（需联网），语速偏慢（−5%），约 100 字，按 L1–L4 分四句，落在各段开头。
- 中段"静→爆"：18.5s 暗场重拍（`cue.climax2`）。
- 声音设计表：

| 段 | 底噪 | 质感床 | 主要拟音 | 配乐状态 |
|---|---|---|---|---|
| 01 一份报销 | 室内底 | warm | 纸张摩擦、荧光笔划过（轻气声）、超 ¥200 飞出的 focus-air | F 大调动机呈现，拨弦 |
| 02 一句话走完流程 | 室内底 | air | 键盘（轻）、四张卡 card-land（调内上行）、原文连线 reveal-swell | 动机发展，加竖琴 |
| 03 暗场一亮 | 低频底 | low | 线框点亮（glass 单音）、18.5s 重拍 stamp | climax2：前面静默半小节 → 低频 + 钟琴 → 重拍 |
| 04 两个出口 | 室内底 | glass | 双设备同落 stamp、连线亮 reveal-swell、推送 count-tick | 动机回到原八度，弦乐铺底 |
| 05 数字墙 | 室内底 | tension→warm | 四个数字 count-tick（上行）、28s hero-hit、落版 stamp | 动机升八度收束，大调和弦释怀 |

- 静默与声音转场：三处真静默（0–1.5s / 15.5–16s / 26.5–27s）。转场：03 进暗场用低频长音先进来（15.5s 起渐入）盖过切点；04 回纸面用纸面亮起的环境声拖过切点。

## 质感

- 空间与层次：前景 = 单据 / 界面卡片（清晰）；中景 = 界面背景 / 暗场线框（略虚）；背景 = 纸纹 / 暗场颗粒（虚）。景深靠 FilmPost 的 DOF（对焦到超标行 / 暗场线框中心）。03 暗场有真实辉光和微尘。
- 光：01–02、04–05 是均匀白天光（暖白纸面，很浅阴影）；03 暗场是金色聚光 + 发光点阵。金色是光不是色块。
- 材质：纸 `#FCFAF9` 极淡纸纹；卡片白底 1px 浅描边圆角 12px 阴影 6%；单据 `docPaper` 偏暖带纤维；暗场 `#14110C` + 金色 `#E7C877` 线框。
- 线宽：界面 1px、暗场金色线框 1.5px、原文连线 1px 细线、数字墙细线图示 1px。
- 字号阶梯：标题 56px 粗黑、副句 20px 灰、引语 64px 宋体、大数字 96px 常规、界面字 15px、单号等宽 13px。
- 冲击力：让人记住的那一下是 28s 数字墙第一数字"8,600"落定（hero-hit + 大数字常规字重不加粗的克制）。尺度靠"8,600 份"这个数本身，不靠放大动画；速度靠"静默 → 重击"（26.5s 静默 → 28s 重击）。
